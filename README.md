## Discord-Based Security Bot

This project implements a smart security system that integrates face recognition, ESP32-based control, and scheduled video management with Discord notifications. The bot is designed to automate anomaly detection, capture video streams, and provide real-time alerts directly through a Discord server.

## Overview

🔒 Face Recognition: Detects and recognizes faces using OpenCV.

🤖 ESP32 Integration: Enables hardware-level interaction and bot control.

📡 Discord Bot: Sends notifications, alerts, and status updates to a Discord channel.

🎥 Video Capture & Storage: Handles webcam streaming and recording.

⏱ Scheduler: Automates cleanup and management of stored recordings.


## **File Structure**

botwithesp32.py – ESP32 integration and bot communication.

facerecog.py – Face recognition logic using OpenCV.

main.py – Handles real-time video capture and scaling.

scheduler.py – Automates cleanup of stored recordings.
